# AI-use statement (template)

Many universities, journals and funders now expect you to **disclose** how you used generative AI.
Always check your university's and target journal's current policy, and agree it with your supervisor.
Keep a simple log as you work (see the bottom of this page). It makes writing this statement easy.

---

## Template

> **Use of generative AI tools.** In preparing this [thesis / article / report], the author used
> [tool name and version, e.g. "ChatGPT (GPT-x, OpenAI)", "Claude (Anthropic)", "GitHub Copilot"]
> between [month year] and [month year] for the following purposes:
> [choose and edit:]
> - suggesting and debugging Python code for data cleaning, analysis and visualisation;
> - explaining statistical methods and software error messages;
> - improving the grammar and clarity of text written by the author.
>
> All AI-generated code was reviewed, tested and run by the author, and all results reported were
> produced by the author's own code, available at [GitHub / Zenodo DOI link].
> Generative AI was **not** used to [generate data / write the literature review / produce references /
> interpret findings without verification]. No confidential or personal data were shared with AI tools.
> The author takes full responsibility for the content of this work.

---

## Do / Don't

| ✅ Generally acceptable (if disclosed) | ⛔ Not acceptable |
|---|---|
| Debugging and explaining code | Listing AI as an author |
| Suggesting analysis approaches you then check | Inventing or "filling in" data |
| Language editing of your own writing | Unverified references or quotations |
| Brainstorming questions and counter-arguments | Pasting confidential or participant data into public tools |
| | Presenting AI-written text as your own original writing |
